# Nutrivivi

O projeto **Nutrivivi** é um sistema web completo para uma nutricionista.

## Tecnologias (Stack)

* **Backend:** Python, Django, Django REST Framework, PostgreSQL
* **Frontend:** Next.js, React, Ant Design
* **Infraestrutura:** Docker, Docker Compose, Nginx
